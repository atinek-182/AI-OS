## 2. Categorized Sub-Categorization Options (INFER / ASK / RECOMMEND)

### INFER (Derived from Codebase Constraints)
- **File Count**: 205 atomic Markdown files across 7 sub-vault directories.
- **Frontmatter Standard**: 100% of files have standardized YAML frontmatter headers.
- **Skill Engine**: `website-design-engine` v5.1 reads `references/awwwards-research-vault/SKILL_ROUTING_MAP.md`.

### RECOMMEND (Recommended Sub-Categorization Architecture)
- **Option 1: Sub-Category Directory Refactoring with Nested Index Headers [RECOMMENDED]**
  - **Structure**: Organize each of the 7 sub-vaults into explicit sub-category folders (e.g., `04-webgl-threejs-fragment-shaders/01-distortion-and-wave/`, `04-webgl-threejs-fragment-shaders/02-particles-and-gpgpu/`, `04-webgl-threejs-fragment-shaders/03-crt-and-postprocessing/`, `04-webgl-threejs-fragment-shaders/04-3d-stages-and-volumetrics/`).
  - **Index Mechanism**: Place a dedicated `INDEX.md` inside each sub-category folder with explicit `read_triggers` and anchor links.
  - **Skill Routing Update**: Update `SKILL_ROUTING_MAP.md` so that micro-phases (e.g. Phase 4.1 Particle Shaders vs Phase 4.2 Wave Distortion) load the exact sub-category index directly.
  - **Rationale**: Provides 100% structural isolation, eliminates flat folder clutter, and achieves true $O(1)$ token pinpoint precision during skill execution.

### ASK (Alternative Sub-Categorization Options)
- **Option 2: Flat Directory with Tagged Taxonomy Tables & Header Anchors**
  - **Structure**: Keep files in their current 7 flat sub-directories, but restructure each sub-vault's `INDEX.md` into micro-category taxonomy tables with explicit section anchors (e.g. `04-webgl-threejs-fragment-shaders/INDEX.md#particle-shaders`).
  - **Trade-off**: Avoids moving files on disk, but keeps 25-47 files grouped in flat directories.

- **Option 3: Hybrid Micro-Tagging in SKILL_ROUTING_MAP.md Only**
  - **Structure**: Leave sub-vault files completely untouched and add micro-file tag filters inside `SKILL_ROUTING_MAP.md` (e.g., "Phase 4 Shader Step: Read files 12, 13, 21, 24").
  - **Trade-off**: Fragile to file additions or renames; hard to maintain.
